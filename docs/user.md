# Documention for `mibisite` python package

Mibisite combines and standardizes the various data that are relevant to bioremediation modeling and analysis into a single data object with functionality for visualization of the field site data and exporting it to common formats.

## How to use mibitrans

Using your preferred Python IDE, install Mibisite

## Installation

To install mibisite from GitHub repository, do:

```console
git clone git@github.com:MiBiPreT/mibisite.git
cd mibisite
python -m pip install .
```
